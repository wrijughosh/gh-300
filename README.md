# GH-300: GitHub Copilot Certification Study Guide

This repository contains comprehensive study materials for the **GitHub Copilot Certification (GH-300)** exam. The content is organized around the official exam objectives, covering all weighted topic areas.

---

## Exam Objectives Overview

| Domain | Weight |
|---|---|
| [Use GitHub Copilot Responsibly](docs/01-responsible-ai/README.md) | 15–20% |
| [Use GitHub Copilot Features](docs/02-copilot-features/README.md) | 25–30% |
| [Understand GitHub Copilot Data and Architecture](docs/03-data-architecture/README.md) | 10–15% |
| [Apply Prompt Engineering and Context Crafting](docs/04-prompt-engineering/README.md) | 10–15% |
| [Improve Developer Productivity with GitHub Copilot](docs/05-developer-productivity/README.md) | 10–15% |
| [Configure Privacy, Content Exclusions, and Safeguards](docs/06-privacy-safeguards/README.md) | 10–15% |

## How to Use This Guide

1. Start with the [Responsible AI](docs/01-responsible-ai/README.md) section to build a foundational understanding.
2. Work through each domain in order, or jump to the section most relevant to your current knowledge gaps.
3. Pay extra attention to the **Features** section (25–30%) as it carries the most weight.
4. Use the key terms and review questions at the end of each section to self-assess.
