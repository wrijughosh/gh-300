# Domain 4: Apply Prompt Engineering and Context Crafting (10–15%)

This domain covers the principles and techniques for writing effective prompts for GitHub Copilot, including understanding how context is determined and how to optimize prompts for performance.

---

## Exam Objectives

- [Crafting Effective Prompts](effective-prompts.md)
- [Engineering Prompts for Performance](prompt-performance.md)

---

## Key Themes

1. **Prompt quality directly affects output quality**: A well-crafted prompt produces better, more relevant suggestions.
2. **Context is automatically determined** but can be guided through file structure, comments, and chat history.
3. **Zero-shot and few-shot prompting** are fundamental techniques applicable to both Chat and inline contexts.
4. **Chat history is part of the context**: Copilot uses prior conversation turns to inform subsequent responses.

---

## Quick Reference

| Technique | Description |
|---|---|
| Zero-shot prompting | Ask for output without providing examples |
| Few-shot prompting | Provide 1–3 examples before asking for output |
| Chain-of-thought | Ask Copilot to reason step-by-step |
| Role prompting | Assign a specific role ("Act as a security reviewer...") |
| Context loading | Open relevant files before prompting |
| Explicit constraints | Specify language, framework, style, and limitations |
