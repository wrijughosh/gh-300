# Domain 2: Use GitHub Copilot Features (25–30%)

This is the highest-weighted domain on the exam. It covers all of the primary ways GitHub Copilot can be used: in the IDE, via the CLI, through advanced features like Agent Mode and MCP, and at the organization level.

---

## Exam Objectives

- [Using GitHub Copilot in the IDE](ide-usage.md)
- [Using GitHub Copilot CLI](copilot-cli.md)
- [Advanced Features: Agent Mode, Copilot Edits, MCP, and More](advanced-features.md)
- [Organization-Wide Settings and Policies](organization-settings.md)

---

## Key Themes

1. **Multiple interaction surfaces**: Copilot is accessible through inline suggestions, Chat, CLI, and agent mode—each suited to different tasks.
2. **Agent Mode and Sub-Agents** enable complex, multi-step agentic workflows directly in the IDE.
3. **Organization policies** control feature availability and ensure consistent, compliant use at scale.

---

## Feature Summary Table

| Feature | Where Available | Best For |
|---|---|---|
| Inline suggestions | IDE | Code completion while typing |
| Copilot Chat (IDE) | VS Code, JetBrains, etc. | Questions, explanations, refactoring |
| Copilot Chat (github.com) | Web | Repo-wide questions |
| Copilot CLI | Terminal | Shell commands, script generation |
| Agent Mode | VS Code | Multi-step autonomous coding tasks |
| Copilot Edits | VS Code | Targeted multi-file refactoring |
| Spaces | github.com | Collaborative AI workspaces |
| Spark | github.com | App creation from natural language |
| PR Summaries | github.com Pull Requests | Auto-generated PR descriptions |
| MCP | VS Code / IDE | Extended tool integrations |
