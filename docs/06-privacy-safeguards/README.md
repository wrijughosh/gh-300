# Domain 6: Configure Privacy, Content Exclusions, and Safeguards (10–15%)

This domain covers the configuration options available in GitHub Copilot for managing privacy, excluding sensitive content, and applying safeguards to ensure compliant and responsible use.

---

## Exam Objectives

- [Managing Privacy Settings and Exclusions](privacy-settings.md)
- [Applying Safeguards and Troubleshooting](safeguards.md)

---

## Key Themes

1. **Privacy settings differ by plan**: Individual, Business, and Enterprise have different defaults and options.
2. **Content exclusions** protect sensitive files from being used as context.
3. **Public code matching** reduces license risk.
4. **Ownership of outputs** is a nuanced topic with no universal legal answer.
5. **Troubleshooting** Copilot issues requires understanding where in the pipeline a problem originates.

---

## Quick Reference

| Setting | Where to Configure | Default |
|---|---|---|
| Training data opt-out | Personal GitHub Settings or Org Settings | ON for Individual, OFF for Business/Enterprise |
| Content exclusions | Repository Settings or Org Settings | None configured |
| Public code matching filter | Org Settings → Copilot → Policies | Allowed (Block to enable filter) |
| Copilot in specific files | Editor settings or IDE config | All files included |
