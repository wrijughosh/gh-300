## Key Themes

1. **Responsible AI is not optional.** GitHub Copilot is built on Microsoft's Responsible AI principles, and users share responsibility for the output they accept and ship.
2. **AI output requires human validation.** Copilot suggestions must be reviewed, tested, and verified before being committed to production code.
3. **Awareness of limitations** reduces over-reliance and helps developers use AI as an assistant rather than an authority.

## Quick Reference

| Concept | Key Point |
|---|---|

| Hallucination | AI generates plausible but incorrect information |
